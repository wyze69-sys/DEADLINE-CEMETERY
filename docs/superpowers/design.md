# Deadline Cemetery — approved MVP design

Three screens: paste an assignment brief → review editable, source-linked task candidates → confirm into a persisted task cemetery. No automatic sample data. Local deterministic extraction is explicitly not AI. Text only; no network models or credential discovery.

Palette: moonlit ink #14131e, plum #292235, parchment #f3ead8, amber #e8ba77, muted lavender #b4adc3, rose #eaa8ac. Georgia display titles and system sans body keep the app usable offline. Wide editorial headings, quiet inset forms, and arched grave-shaped task cards supply the signature. Grave silhouettes encode task records, not decorative icon clutter. Desktop split intro/form and responsive single-column mobile layout. Explicit labels, visible focus, readable contrast, reduced-motion support.

Dashboard: actual local-day overdue/upcoming/undated/completed states, filters, source evidence, completion, edit and confirmed deletion. Review makes uncertainty visible and never invents a missing year. Exact quotes link back to highlighted source. Clear empty/loading/error feedback. No AI claims, inflated extraction certainty, or fake hackathon compliance.

Critique: avoid generic analytics tiles and spooky emoji; use a small cemetery field whose cards are still readable conventional task controls. Keep the primary workflow and evidence clearer than the theme.
