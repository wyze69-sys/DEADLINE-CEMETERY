# Student workload planner design
Authorized autonomous scope: retain the local source-verified intake and atomic store; add read-time legacy defaults, explicit assignment metadata, effort/blockers and a deterministic server planner. No inferred submission dates, AI scores, task splitting or completion-as-submission. Rescue tonight is the main action. Rank dated work chronologically then importance and stable ID; place undated work last and identify it separately. Greedy whole-task selection can skip an oversized task. Capacity warning compares due workload to one day only. Browser budget preference is honestly localStorage. Submitted records retain tasks and appear in an archive. Confirm submission with unfinished work. No external integrations or seeded data.
