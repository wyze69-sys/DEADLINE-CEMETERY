
# Kiro workspace configuration

This directory contains project steering for future work in Kiro. The steering documents describe the existing application and rules for changing it; they are not evidence that Kiro built or tested the project.

- `steering/product.md`: product purpose, scope, and truthful behavior.
- `steering/tech.md`: stack, local run commands, verification, and safety.
- `steering/structure.md`: source layout and change boundaries.

Open the repository root in Kiro and use the steering during an actual development session. Record only work actually performed when writing the hackathon submission. No custom agents, hooks, MCP servers, powers, or property-based testing configuration are claimed here.
